# Glossary — ATA 05

- **Interval:** The repeat period for a maintenance task (FH/FC/Calendar).
- **Threshold:** The initial trigger value for first execution (may differ from repeat interval).
- **Effectivity:** Applicability scope (variant, MSN range, configuration, etc.).
- **Overdue:** Condition where task execution exceeds allowed tolerance.
- **Escalation Rule:** Defined actions/limitations when approaching or exceeding due point.
